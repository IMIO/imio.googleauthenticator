<objective>
Harden the MFA-19 path the tracer proved, and satisfy the two standing constraints that apply
specifically to it.

Three things:

1. **Extend the PAS-plugin state-write guard.** `tests/test_pas_plugin.py::test_no_second_factor_state_written_from_the_plugin`
   is a source-level guard that no second-factor state is written from the plugin or the subscriber.
   The roadmap says it must be extended, not worked around. This phase adds a property and a writer;
   both go into it, and it gains a positive assertion that the routing read exists.
2. **Close D-07.** A user with the flag set and no stored seed is now the common case, not an edge
   case, and on a site with a missing or malformed seed encryption key that account's login produces
   an uncontrolled error page from inside `send_2fa_redirect` instead of a clean refusal.
3. **Prove the new property is member-data only** — declared, round-tripping, and absent from the
   user-profile schema and the adapter (D-17).

Purpose: the tracer proved the happy path. These are the three places the same path fails badly if
nobody looks.
Output: one new helper, a synchronous check in the login path, an extended guard test, and coverage
for the property and the invalid-signature refusal.
</objective>
