|----------|-------------|
| Plone site `acl_users` → Zope root user folder | The plugin's authority stops here. Root accounts are authenticated above the site and this package cannot gate them. |

| iMio scripts and integrations → this site over Basic Auth | Consumers outside this repository, not enumerable from inside it. |
