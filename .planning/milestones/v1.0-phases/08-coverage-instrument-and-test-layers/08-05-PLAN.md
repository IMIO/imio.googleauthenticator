<objective>
Clear all of `bin/code-analysis`'s findings so it exits 0 and the buildout's own pre-commit hook
starts working, then correct the two documents this phase makes wrong.

Purpose: the hook has been failing since Phase 1, which trained every commit in phases 1 through 7
to pass `--no-verify`. A gate everyone routes around is not a gate. This plan is deliberately last
(D-06): the mechanical import sweep rewrites the import block of every test file, and plans 08-02
through 08-04 rewrote `setUp` and added imports in those same files — sequencing the sweep last means
the two edits never overlap and the sweep covers whatever the earlier plans added. The accepted
consequence is that every commit before this one needed `--no-verify` and the hook goes green exactly
once, at the end.
Output: `bin/code-analysis` exit 0, a commit made without `--no-verify`, and two documents that no
longer contradict the tree.
</objective>
